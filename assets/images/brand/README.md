# MachiVerse Brand Assets

This directory contains reusable official brand assets for MachiVerse.

## Official logo

- `MachiVerse_Official_Logo.svg` — canonical scalable MachiVerse logo, based on the branding used in the project social preview.

The official mark uses the geometric `M`, four-point sparkle, and `MachiVerse` wordmark with the cyan-accented `V`.

When using the logo in promotional materials:

- keep the logo proportions unchanged;
- use the official asset rather than independently generated replacement wordmarks or symbols;
- keep sufficient contrast around the white/cyan mark (dark backgrounds are recommended for the primary version).
